# Contributing

Issues and pull requests are welcome.

This repository is a standalone LuCI theme intended to be copied into an
OpenWrt LuCI feed under `themes/luci-theme-sophos/`.

For compatibility reports include OpenWrt version, LuCI version, browser,
theme version and a screenshot or console output where relevant.

Keep CSS names scoped with `sophos-` where practical and avoid changing global
LuCI behavior when a theme-local style is sufficient.
